## Findings

| Priority | Step | Finding | Fix |
|---|---|---|---|
| P1 | Lesson overview | Desktop card proportions were stacked on mobile, making the course summary consume most of the first screen. | Reduce card padding, hide repeated description, shorten progress spacing, and compress the four-step bar. |
| P1 | Round 1 | Heading and listening panel were too large, requiring multiple screens before the next action. | Reduce mobile display type, card padding, body copy, and decorative element size. |
| P1 | Audio controls | Controls wrapped inefficiently and used excessive vertical space. | Keep the primary play control full-width and place supporting controls compactly below it. |
| P2 | Instructions | Two guidance cards were visually heavier than their supporting role. | Reduce card padding, number size, gap, and line height. |
| P2 | Navigation | Previous and Next were stacked, adding another full row of scrolling. | Place both actions on one mobile grid row with greater emphasis on Next. |
| P2 | Page ending | Landing-page bottom spacing affected the free lesson, producing unnecessary blank space. | Scope bottom padding only to pages that contain the mobile conversion bar. |

## Accessibility notes

- Controls keep a minimum target height of 40–42 CSS pixels.
- Text is reduced without dropping core body copy below 12 CSS pixels.
- Active steps retain color, weight, and filled-number differentiation.
- Screenshot evidence cannot confirm keyboard focus, screen-reader output, audio availability, or browser zoom behavior.
